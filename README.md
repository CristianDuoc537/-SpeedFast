📘 Descripción general del sistema

SpeedFast es una aplicación desarrollada con el objetivo de aplicar los principales conceptos de la Programación Orientada a Objetos, utilizando Java como lenguaje de programación. El proyecto busca representar y gestionar las diferentes entidades y operaciones relacionadas con el funcionamiento de un servicio de transporte.
